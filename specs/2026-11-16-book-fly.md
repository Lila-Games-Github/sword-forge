# Books fly to the skill tree (R125, 2026-11-16)

Build: `Swordforge_looptest_landscape.html`. Tracker: R125 in `specs/2026-10-23-ftue-smelter-rework-plan.md`. Test:
`node tooling/skills/skills.test.mjs` (the R125 checks).

Owner (2026-11-16): "i want the skill book icons to fly to the skill tree tab, on collection the same way as coins fly".

## What happens

When the sword's route passes over a book on the map (`checkBooks`, `takeBook`), the exp is given at once, as before, and the
book fades with its "+exp" pop, as before. Now also:

- **The flight:** copies of the book's own map icon (the open book on its coloured tab: green for a small book, amber for a
  large one, gold for the Sword Master's) fly from the book to the **skill tree button** (`#skillBtn`, the inventory panel's
  top left), the way coins fly to the gold: the same function (`flyCoins`), count, arc and timing.
- **The landing:** when the last copy lands, the skill tree button's picture glows once (`#skillBtn.gained`).

## Values

| What | Value | Note |
| --- | --- | --- |
| Copies | 5 | `COIN_N`, the coins' count |
| Flight | 650 ms each, 70 ms apart, an arc through the middle | `COIN_MS`, `COIN_GAP`, the coins' path |
| Icon size | 22 px | the coins are 20 px |
| Glow | 600 ms, brightness 1.35 and a gold glow on the picture | `#skillBtn.gained .sk-art` |

## Rules

- The flight only shows the exp; the exp, the level and the talent point are given at pickup, as before. Nothing waits on the
  flight.
- A game loaded from a save marks its taken books without a flight (they were taken before).
