# Chests

Source: https://shop-titans.fandom.com/wiki/Chests

Chests are sometimes given as a reward for completing quests . Each dungeon has a different type of chest. A key of the same type is required to unlock the chest. 

There are currently 18 Chests available. Each chest contains four of the following:
