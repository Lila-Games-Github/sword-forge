# Carpenter

Source: https://shop-titans.fandom.com/wiki/Carpenter

## Allan 

### Role 
Carpenter 

### Production Type 
Worker 

### Building 
Wood Workshop 

## Unlock 

### Merchant Level 
3 

### Gold 
2,500 

### Gems 
50 Allan is a worker that resides in the wood workshop . He allows for the crafting of certain weapons . 

## Blueprints [ ] 
Unlocking this worker grants the following blueprints : 
- Cudgel 
- Carved Branch 

## Crafting List [ ] 
Allan can craft some of the following types of items, which grant experience . 
- Axes 
- Bows 
- Maces 
- Shields 
- Spears 
- Staves
